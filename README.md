🛍️ ELASY Store
ELASY Store is a modern e-commerce platform specializing in PC components and gaming accessories, designed to provide a seamless and responsive user experience with a sleek and attractive interface.
 
✨ Key Features
🛒 Seamless Shopping Experience - Intuitive browsing and product addition to cart

📱 Fully Responsive Design - Works perfectly on all screen sizes

⚡ Blazing Fast Performance - Built with Vite for optimal speed

🔍 Smart Product Search - Instant search with real-time results

🎯 Interactive UI - Smooth animations with Framer Motion

🛍️ Dynamic Cart - Real-time cart updates and item tracking

🔄 State Management - Efficient state handling with Redux Toolkit

🎨 Modern Styling - Beautiful UI with Tailwind CSS

🚀 Live Demo
Check out the live demo: https://mohamed-khaled-22.github.io/ELASY-Store/

🛠️ Tech Stack
Frontend Framework: React 18
State Management: Redux Toolkit
Routing: React Router DOM
Styling: Tailwind CSS
Animations: Framer Motion
Slider Component: Swiper.js
Icons: Lucide React
Build Tool: Vite.js

📦 Installation
Clone the repository

git clone https://github.com/Mohamed-khaled-22/ELASY-Store.git
cd elasy-store
Install dependencies

npm install
Start the development server

npm run dev
Open your browser
Navigate to http://localhost:5173

🎮 How to Use
Browse Products: Navigate through categories or use the search bar

View Details: Click on any product to see detailed information

Add to Cart: Select products and add them to your shopping cart

Checkout: Proceed to checkout when ready to purchase

Account Management: Sign in to access your order history and preferences
